# Copy de raw.vives

## Una línea

raw.vives es un archivo fotográfico editorial bilingüe que conecta narrativa visual, series y exploración accesible.

## Breve

Diseñé y desarrollé raw.vives para convertir 30 fotografías en un recorrido editorial con archivo, búsqueda, fichas y tres series conectadas.

## Media

raw.vives combina dirección visual, curación y arquitectura frontend para presentar 30 fotografías como un archivo narrativo en español e inglés. El proyecto incluye tres series editoriales, búsqueda y filtros, fichas con fullscreen y navegación contextual, motion con reduced motion y entrega estática en Cloudflare Workers.

## Técnica

Next.js App Router genera 81 páginas estáticas localizadas. Configuraciones centrales modelan curación, motion y series; 105 tests validan datos y navegación. GitHub Actions controla la entrega a Cloudflare Workers con credenciales de mínimo privilegio.

## Tecnologías

Next.js 16, React 19, TypeScript, Tailwind CSS 4, GSAP, Three.js, Lenis, Sharp, Cloudflare Workers y GitHub Actions.

## Tres aprendizajes

1. La curación aporta más continuidad que aumentar el volumen de imágenes.
2. Una gramática limitada de motion mantiene identidad sin penalizar claridad.
3. La navegación contextual necesita URLs directas y un fallback editorial estable.
